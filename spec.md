# Specification

## Summary
**Goal:** Build a responsive, multi-page Italian language learning website called "Reema's Italian Studio" with a consistent Italian flag color theme, static content, and no backend.

**Planned changes:**
- Set up a React app with React Router for five pages: Home, Lessons, Videos, About, and Contact
- Implement a sticky navbar with "Reema's Italian Studio" brand, nav links, Italian flag color accents, and a mobile hamburger menu
- Build the Home page with a hero section (heading, tagline, two CTA buttons), a Featured Lessons section (3 cards), a Testimonials section (3+ dummy testimonials from Indian learners), and a footer
- Build the Lessons page with three categorized sections (Beginner, Vocabulary, Grammar), each containing at least 4 lesson cards with title, description, and a "Start Lesson" button
- Build the Videos page with a responsive grid of at least 6 embedded YouTube video iframes, each with a title
- Build the About page with three sections: "Meet Your Teacher" (placeholder avatar, name Reema, bio), "Our Mission", and "Why Learn Italian?" (5+ benefits)
- Build the Contact page with a Name/Email/Message form showing a frontend-only success message on submit, plus social media links
- Create a reusable Footer component (channel name, tagline, nav links, social icons — YouTube, Instagram, Facebook) shown on all pages
- Apply a consistent Italian flag palette (#009246 green, #FFFFFF white, #CE2B37 red) on a warm off-white (#FAF8F5) background, with serif display headings, sans-serif body text, smooth scrolling, and Italian flag accent dividers throughout

**User-visible outcome:** Visitors can browse a polished Italian language learning website, explore categorized lessons, watch embedded videos, learn about the teacher, and submit a contact form — all with a cohesive Italian-themed design across all pages.
